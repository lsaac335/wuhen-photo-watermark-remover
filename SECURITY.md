# Security Policy

## Reporting a vulnerability

Please do not disclose security vulnerabilities in a public issue. Contact the repository owner privately through their GitHub profile and include only the minimum information needed to reproduce the problem.

Do not include private photos, authentication material, API keys, or other sensitive data in a report.

## Privacy model

The application is designed to process images locally. A change that introduces image uploads, telemetry, or remote processing must be clearly disclosed and opt-in.
