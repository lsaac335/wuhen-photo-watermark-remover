# Contributing

Thanks for helping improve Wuhen Photo Watermark Remover.

## Before opening an issue

- Search existing issues first.
- Do not upload private or copyrighted photos you are not allowed to share.
- Describe the operating system, app version, image dimensions, and the steps that reproduce the problem.
- Use a synthetic or safely shareable sample image whenever possible.

## Pull requests

1. Create a focused branch.
2. Keep image processing local and avoid adding telemetry or mandatory cloud services.
3. Run `pnpm desktop:web`, `pnpm build`, and `pnpm test`.
4. Explain the user-visible change and how it was verified.
